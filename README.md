# 👋 Hi, I'm Fernando

Full-Stack Developer based in Seville, Spain · also known as **Tyralk** (or Eirems in some communities).

## About me

I'm a full-stack developer at Numier TPV, a POS software company. Day to day I work on the web side of the product: back-office dashboards where businesses track sales, expenses and suppliers, digital menus, online ordering and the odd custom CRM. Mostly PHP (Slim and Laravel) with Vue 2/3, plus Flutter or Android when a project needs an app.

A lot of the work happens in the database, on top of a fair amount of legacy code, so query optimization and database administration are a big part of the job.

Lately I've been building MCP servers to bring AI tools into everyday development work.

Before all this I was a 3D artist in the games industry, working on characters, texturing and rigging. Rigging is where I wrote my first scripts, in Python and MEL.

## 🛠️ Tech

- **Backend:** PHP (Slim, Laravel), Java (Spring Boot, Hibernate), Python
- **Frontend:** Vue 2 & 3, Tailwind, PrimeVue
- **Mobile:** Flutter, Android (Java), currently moving to Kotlin + Jetpack Compose
- **Databases:** MySQL, SQL Server, MongoDB, Firebase · query optimization, indexing, administration
- **AI tooling:** MCP servers, AI-assisted development workflows
- **Learning:** Docker, Kubernetes, Kotlin
